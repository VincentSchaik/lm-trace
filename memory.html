How it works

A language model has no memory. Each request starts empty. The harness (the program around the model) decides what goes into each request.

Hallucinations: without the facts in the request, the model answers from its training data. It often invents names, dates or links. Memory puts the facts into the request (), but a search can miss a fact and a summary can lose details.
