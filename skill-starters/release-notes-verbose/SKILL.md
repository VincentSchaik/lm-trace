# Release notes skill

## What are release notes?

Release notes are documents that are distributed with software products. They describe the changes, enhancements and bug fixes in a new version of the software. Release notes help users understand what is new and what has changed. They are an important part of software development and communication with users. Good release notes are clear, concise and well organized. They can be published on a website, in an app store, in an email or in a document.

## Why release notes matter

Users want to know what changed. Developers want a record of their work. Product managers use release notes to communicate value. Support teams use them to answer questions. Without release notes, users may miss new features or be surprised by changes.

## Formats

You can use many formats for release notes:

- Keep a Changelog (Added, Changed, Deprecated, Removed, Fixed, Security)
- A narrative blog post
- A bulleted list
- A table with columns for type, description and ticket
- Conventional Commits groups (feat, fix, chore, docs)
- Semantic release style

Choose the format that you think is best. Handle all the changes appropriately and follow best practices.
