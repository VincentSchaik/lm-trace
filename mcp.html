MCP

A playground for MCP, the Model Context Protocol: one standard way to connect a model to tools and data. Here LM Studio is the MCP host: it starts the local servers and connects to the remote servers of its mcp.json, gives their tools to the LLM, and runs each tool call. This page sends your message and shows each step.
How it works
MCP hostThe AI application that coordinates and manages one MCP client for each server. Here LM Studio.
MCP clientA part of the host. It holds one connection to one server and sends it JSON-RPC messages.
MCP serverA program that gives context: tools, resources and prompts. Local (stdio: the host starts it as a child process) or remote (Streamable HTTP: a URL).
LLMThe model. It only reads and writes text. MCP does not say how the host uses the LLM. LM Studio calls it two times when it uses a tool.

A server has three kinds of capabilities. Tools are model-controlled: the model selects one and writes the call. Resources are application-controlled: data, like a file, that the host reads and adds to the context. Prompts are user-controlled: ready messages that you select, like a slash command.

  1. Discovery · each MCP client connects to its server (initialize) and asks for the tools (tools/list). In the next turn of the same chat, it asks only for the tools.
  2. Prompt and tools · the MCP host puts your message and the tool definitions into the prompt of the LLM.
  3. Tool selection · the LLM selects a tool and writes the call, or answers at once.
  4. Tool execution · the MCP host routes the call to the MCP client of that server, which sends tools/call. The server calls its API or reads its files.
  5. Result · the server returns the result to the MCP client.
  6. Prompt and tool output · the MCP host adds the tool call and the result to the prompt, and calls the LLM again.
  7. Answer · the LLM reads the result and writes the answer.

The LLM never talks to a server. It only writes text; the MCP host does the rest. Over the API, LM Studio runs each tool call at once: there is no approval step.
