A language model never reads letters. First, the tokenizer cuts the text into tokens and gives each token an ID. Then the model looks up each ID in its embedding table and gets a list of numbers: the embedding. These lists are the input of the first layer. This page shows both steps with the real data of the selected model.

→
1Tokens text → token IDs

The tokenizer cuts the text into tokens: whole words, parts of words, single characters or symbols. A space is usually part of the next token (·Paris). Each token has an ID: its row number in the vocabulary of the model. The model receives only the list of IDs. Click a token to see its embedding.

2Embeddings token ID → list of numbers

The embedding table has one row for each token in the vocabulary. The model takes the row of each token ID: a list of numbers, the embedding. The same token always gets the same row, in any sentence. The layers of the model add the context later. Blue = positive, grey = negative. These are the real numbers from the model file.
