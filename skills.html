A playground for Agent Skills. Turn skills on, send a message, and watch each stage join the context.
How it works

What is a skill? A folder that teaches a model how to do one task your way, every time: the steps, the format, the checks. A model knows a lot, but not how your team writes meeting notes or release notes. A skill gives it that knowledge, with scripts and reference files when the task needs them.

Why three stages? A model can have many skills on hand and pay only for the ones it uses. It reads the name and description of each skill, and loads the rest only when a task needs it:

DiscoveryName and description of each skill, in the system promptAlways · ~100 tokens each ActivationThe body of SKILL.md: load_skill, or you type /nameWhen a task fits · < 5,000 tokens ExecutionA file or a script of the skill (a script asks you first)When the instructions say so 
my-skill/
├── SKILL.md      # Required · frontmatter: Discovery · body: Activation
├── scripts/      # Optional · code: Execution
├── references/   # Optional · docs: Execution
└── assets/       # Optional · templates, images, data: Execution
