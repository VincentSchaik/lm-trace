# Sample folder of the MCP page

The Filesystem MCP server of the MCP page gives the model access to this folder only, read only
(`--read-only`). The model can list the files and read them. It cannot change, move or delete a file.

Files:

- `trip-plan.md`: a weekend trip plan with a budget
- `reading-list.md`: books and articles about AI agents
- `expenses-2026-11.csv`: the expenses of one month
