A model cannot run a tool. It only writes text that asks for a tool. The harness (the program around the model) reads that text, runs the tool and sends the result back.
How it works
  1. Tool creation · Tools tab: Create tool. A tool is a function with a name, a description and parameters.
  2. Tool definition · Sending request, Applying chat template. LM Studio (structured function calling): the tools go as JSON schemas. Custom note: the tools are text in the system prompt.
  3. Tool selection · Generating tokens. The model thinks, and selects a tool or no tool.
  4. Tool calling · Generating tokens: the model writes the call. Parsing output, Serializing JSON: LM Studio parses it. Parsing tool_calls, Validating tool call: the harness parses and validates it. Executing tool: the server executes it. In Step mode, you approve it first.
  5. Output processing · Appending observation: the result goes back to the model as an observation. In the next model call, the model writes the answer.

Some models learned special tool tokens in training. LM Studio puts the tools into the chat template of these models. Other models get the tools as a text note, and must follow it.
