Settings

Each model has its own format. These values tell the pages the format of a model, so they work for any model. The server saves them, so every page reads the same values.

Model formats

Where the thinking starts and ends, in the raw text of the model

LM Studio sends the thinking in its own field (reasoning_content or reasoning) when it can. Then the pages use that field, and a value here is not necessary. To find the values for a new model: on the Tools page, open a Model row, click Details, then Raw. Copy the text before and after the thinking.

Embedding prefixes

The text before a query and before a document, for each embedding model

Some embedding models were trained with a short text in front of each input: one for a query, one for a document. With the same text, the search is usually better. The model card of the model gives these values. The RAG page, the Memory page and the search_memory tool use them. A model without a row gets no prefix.
